## 관리 범위

- 프론트 화면, 상호작용, Mock 데이터, 프론트 전용 실행 환경을 관리한다.
- 신규 번호는 `TASK-FE-001`부터 사용한다. 문서는 `../tasks/TASK-FE-XXX.md`에
  보관한다. 기존 Task의 이동·번호 변경은 하지 않는다.
- 공통 지침과 전체 로드맵은 [루트 계획](../PLAN.md), 백엔드 작업은
  [백엔드 계획](../backend/PLAN.md)을 따른다.
- 이 문서는 프론트 작업 목록과 상태 요약이다. 실제 변경 범위·검증 결과는
  개별 Task 문서가 기준이며, 완료 시 이 목록과 [진행 로그](../PROGRESS.md)에
  요약을 반영한다. 상세 구현 기록을 여러 문서에 복사하지 않는다.
- 한 Task에 프론트와 백엔드 구현을 함께 넣지 않는다. API 연결이 필요한 경우
  요청 조건·응답 형태를 합의하고, FE/BE Task를 별도로 연결한다.
- 두 영역에 함께 영향을 주는 DB·공통 CI·배포 작업은 필요할 때
  `TASK-INFRA-*`로 작성한다. 프론트만 실행하는 Docker 설정은 FE 범위다.
