# SPEC.md - 제품 명세

## 개요

VALORANT 플레이어 성장 플랫폼. 전적 검색과 라인업 정보를 제공하며, 장기적으로 상위 랭커 데이터 기반의 개선 피드백을 목표로 한다.

## 목표 우선순위

### 1차 목표

- VALORANT 전적 검색 사이트의 프로토타입 제작
- **Mock JSON 파일 기반**으로 검색, 프로필, 경기 목록, 경기 상세 흐름 구현
- 모든 플레이어/경기 데이터는 정적 JSON 파일에서 로드 (실제 Riot API 호출 없음)
- 실제 배포 가능한 형태로 완성
- Riot Production API 신청 준비

### 2차 목표

- Riot API 승인 대기 기간 동안 맵·요원별 라인업 기능 구현
- 라인업 검색, 상세 화면, 즐겨찾기, 패치 검증 상태 제공
- 커뮤니티는 라인업 댓글과 작동 여부 신고 정도로 제한

### 3차 목표

- Riot Production API 연동
- 실제 플레이어 전적 조회
- RSO 인증

### 4차 목표

- 상위 랭커 데이터 수집 및 통계 기반 분석
- 맵/요원/역할/티어별 기준 통계 생성
- 사용자 전적과 기준 통계 비교
- 통계 기반 피드백 생성
- AI 자연어 설명

### 5차 목표

- 웹 백엔드와 데이터를 재사용하는 Overwolf 앱 개발
- 게임 중 현재 맵과 요원에 맞는 라인업을 사용자가 직접 조회
- 경기 후 분석 요약 제공

### 후순위

- 감도 계산과 기록
- 다국어 콜아웃
- 음성채팅 번역 연구
- 자유게시판과 파티 모집

## 핵심 사용자 흐름

### 전적 검색 흐름 (Phase 1-2)

```
홈
→ Riot ID 검색 또는 데모 계정 선택
→ 플레이어 프로필
→ 최근 경기 목록
→ 경기 상세
```

### 라인업 흐름 (Phase 3)

```
라인업 검색 (맵/요원/스킬 필터)
→ 라인업 목록
→ 라인업 상세
→ 즐겨찾기 추가
→ 작동 여부 신고
```

### 분석 피드백 흐름 (Phase 5, 장기)

```
플레이어 프로필
→ 경기 상세
→ 통계 기반 비교 분석
→ 개선 피드백
→ AI 자연어 설명
```

## 제품 원칙

### 반드시 지킬 것

1. **공식 데이터 존중**: 자체 MMR이나 비공식 티어를 만들지 않는다.
2. **통계 기반 분석**: 분석은 상위 랭커 데이터 기반 통계 비교로 제공한다.
3. **충분한 표본 확보**: 충분한 표본 수와 데이터 품질이 확보되기 전에는 피드백을 제공하지 않는다.
4. **AI 역할 제한**: AI는 원시 데이터를 직접 판단하지 않고 계산된 비교 결과를 자연어로 설명하는 용도로만 사용한다.
5. **Mock 우선 동작**: Riot API 승인 전에도 전적 검색 흐름이 동작해야 한다.
6. **공식 API만 사용**: 비공식 Riot 클라이언트 API를 핵심 데이터 소스로 사용하지 않는다.

### 초기 MVP에서 제외

- 분석 피드백 (상위 랭커 통계 확보 전까지)
- 커뮤니티 기능 (게시판, 라인업 댓글 외)
- 실시간 번역
- 파티 모집
- 감도 계산기

## 데이터 모델 (개요)

### 플레이어

- Riot ID (게임네임#태그)
- PUUID
- 현재 랭크
- 최근 경기 목록
- 통계 요약

### 경기

- 경기 ID
- 맵
- 모드
- 참가자 목록
- 라운드별 데이터
- 개인 성적

### 라인업

- 라인업 ID
- 맵
- 요원
- 스킬
- 위치 (시작점, 조준점)
- 이미지/영상
- 패치 버전
- 검증 상태

### 상위 랭커 통계 (Phase 5)

- 기준 조건 (맵, 요원, 역할, 티어, 진영)
- 표본 수
- 평균/중앙값/분포
- 마지막 업데이트 일시
- 신뢰도 등급

### 분석 (Phase 5)

- 경기 ID
- 비교 기준 통계 ID
- 비교 결과
- 개선 제안
- 표본 수와 신뢰도

## API 엔드포인트 (초안)

### 플레이어

- `GET /api/players/search?riotId={gameName}%23{tagLine}`
- `GET /api/players/{puuid}`
- `GET /api/players/{puuid}/matches`

### 경기

- `GET /api/matches/{matchId}`

### 라인업

- `GET /api/lineups?map={map}&agent={agent}&skill={skill}`
- `GET /api/lineups/{lineupId}`
- `POST /api/lineups/{lineupId}/report`
- `GET /api/lineups/favorites`
- `POST /api/lineups/{lineupId}/favorite`
- `DELETE /api/lineups/{lineupId}/favorite`

### 분석 (Phase 5)

- `GET /api/matches/{matchId}/analysis`
- `GET /api/stats/benchmarks?map={map}&agent={agent}&role={role}&tier={tier}`

## 비기능 요구사항

### 성능

- 검색 응답 시간: 500ms 이내
- 페이지 로드 시간: 2초 이내

### 보안

- Riot Sign On(RSO) 인증 사용 (실제 API 연동 시)
- 사용자 동의 기반 데이터 접근
- 데이터 삭제 요청 지원

### 확장성

- Riot API Adapter 인터페이스로 Mock/실제 API 교체 가능
- 모듈형 모놀리스 구조로 점진적 분리 가능
