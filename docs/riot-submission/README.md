## 신청 전 남은 상태

| 항목 | 상태 |
|---|---|
| 신청용 전적/동의 프로토타입 | 로컬 검증 완료 |
| 신청 설명·심사 동선·공개 URL 후보 | 작성 완료 |
| 실제 문의처·운영 주체·서비스 범위 | 확정 및 한영 화면·신청 문안 반영 완료 |
| 호스팅/분석/문의 처리·보관 사실 | Hobby·분석·Drains 및 문의30일 파기 확인 완료. 국외 처리 상세 고지 검토 남음 |
| 약관·개인정보 최종 승인 | 소유자 확인 대기; 페이지는 초안 유지 |
| 최신 공개 배포 | main b08f9a1, www.game-probe.com 검증 완료 |
| Riot 신청 | 미제출 |

공개 도메인은 main b08f9a1 배포 확인을 완료했습니다. 이후 정책 보완본은 로컬 검토 중입니다.
따라서 기존 사이트 HTTP200을 ‘제출 준비 완료’로 판단하지 않습니다.

실제 API/RSO는 Production Key 승인 후 구현하는 순서로 설명했습니다. 비동의 참가자 정보 보호·서버 동의/철회/삭제는 실제 서비스 공개 전 별도 구현이 필요합니다.
[VALORANT 공식 안내](https://developer.riotgames.com/docs/valorant), [Production Key 신청 안내](https://support-developer.riotgames.com/hc/en-us/articles/22801383038867-Production-Key-Applications)를 기준으로 현재 시연과 향후 기능을 구분했습니다.

최신 정책 보완은 로컬 변경 상태이며 추가 커밋·재배포·Riot 제출을 실행하지 않았습니다. 기존 사용자 파일 `current-screen.png`는 변경하지 않았습니다.

정책 최종화의 실제 수정 내용과 남은 입력: [개인정보 운영안](POLICY-OPERATIONS.md).
