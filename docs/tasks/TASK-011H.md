# TASK-011H: 운영 배포 실행 및 승인

## Status

HUMAN-REQUIRED (사람 수행 필요 — 자동 구현 대상 아님)

> 이 Task는 **사람이 직접 수행**한다. 외부 서비스 로그인, 도메인 구매/DNS
> 변경, 비밀정보 입력, 실제 운영 배포 승인은 AI/Codex가 대신 수행하지 않는다.

## Goal

`docs/PLAN.md` Phase 2 완료 기준 "사이트 배포 완료"를 충족한다. TASK-011이
준비한 배포 설정·CI·문서를 사용해 실제 운영 환경에 배포하고, 운영 배포를
승인한다.

## Context

- 이 단계는 다음 **사람 전용 작업**을 포함한다(요청서에 명시된 사람 작업과
  일치):
  - 외부 서비스 로그인(배포 플랫폼/호스팅 계정)
  - 도메인 구매나 DNS 변경
  - API 키 또는 비밀정보(환경 변수) 입력
  - 실제 운영 배포 승인
- TASK-011D에서 확정한 플랫폼(PENDING-006/007)과 TASK-011이 생성한 설정
  파일·환경 변수 템플릿(`.env.example` 등)을 기준으로 한다.

## Dependencies

- **선행**:
  - TASK-011D (배포 플랫폼·DB 호스팅 결정) — 확정 필요.
  - TASK-011 (배포 환경 구성, 설정·CI·문서) — DONE 필요.
  - TASK-012 / TASK-013 (개인정보처리방침·이용약관 페이지) — 배포 대상에
    포함되어야 함.
  - TASK-013H (법률 문서 최종 승인) — 운영 배포 전 권장(법적 노출 문서가
    최종본이어야 함).
- **후속**: TASK-015H(Riot Developer Portal 신청)는 배포된 공개 URL을
  요구한다.

## Allowed changes

```
docs/tasks/TASK-011H.md   # 배포 실행 결과(배포 URL, 일시 등)를 Result에 기록
```

- 비밀정보 자체는 문서에 기록하지 않는다(키/토큰/비밀번호 평문 금지).
- 소스코드는 변경하지 않는다. 배포 중 설정 수정이 필요하면 TASK-011로
  되돌려 처리한다.

## Forbidden changes

- AI/Codex가 사람 대신 로그인·결제·DNS 변경·비밀정보 입력·배포 승인을 수행
- 비밀정보(API 키, DB 비밀번호 등) 평문을 저장소/문서에 커밋
- `frontend/**`, `backend/**`, `docker/**`, `scripts/**` 소스코드 직접 수정
  (수정 필요 시 TASK-011 경유)

## Acceptance criteria

1. **배포 실행**
   - [ ] 사람이 플랫폼에 로그인하고 TASK-011 설정으로 Frontend(및 결정 시
     Backend)를 배포한다.
   - [ ] 도메인/DNS가 필요한 경우 사람이 설정한다.
   - [ ] 환경 변수/비밀정보를 플랫폼 콘솔에 사람이 입력한다.
2. **공개 접근 확인**
   - [ ] 배포된 공개 URL에서 홈, 플레이어 프로필, 경기 상세, 개인정보처리방침,
     이용약관 페이지가 응답한다.
3. **운영 배포 승인**
   - [ ] 사람이 운영 배포를 승인한다.
   - [ ] 배포 URL, 배포 일시, 사용한 플랫폼을 Result에 기록한다(비밀정보 제외).

## Verification commands

```bash
# 사람이 배포 후 공개 URL 응답을 확인한다 (예시 — 실제 도메인으로 대체)
curl -I https://<배포-도메인>/
curl -I https://<배포-도메인>/privacy
curl -I https://<배포-도메인>/terms
```

## Stop conditions

1. AI/Codex가 로그인·DNS·비밀정보 입력·배포 승인을 대신 수행하도록 요청받는
   경우 — 중단하고 사람 수행을 요청한다.
2. TASK-011 설정이 불완전해 배포가 불가능한 경우 — TASK-011로 되돌린다.
